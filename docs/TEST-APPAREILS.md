# Test sur iPhone — liste à cocher (Fluxe App v1.0.0)

À faire après chaque nouvelle version, sur l'iPhone, avec l'appli installée sur l'écran d'accueil.

## 1. Mise à jour

- [ ] Fermer complètement l'appli (balayer vers le haut), puis la rouvrir.
- [ ] Lancer une séance, toucher le bouton **?** : en bas de la fenêtre d'aide, on lit **« Fluxe v1.0.0 »**. (Sinon : fermer/rouvrir encore une fois.)
- [ ] La progression d'avant est toujours là : même **niveau**, même nombre de **sessions** (🔥), journal intact.

## 2. Hors ligne

- [ ] Activer le **mode avion**.
- [ ] Fermer puis rouvrir l'appli : elle s'affiche normalement (couleurs, titres en police étroite).
- [ ] Faire une **séance complète** (jusqu'à « Flux Terminé ! » et choisir une humeur).
- [ ] L'XP a augmenté et la séance apparaît dans le **Journal**.
- [ ] Désactiver le mode avion.

## 3. Sauvegarde (export / import)

- [ ] Journal → **Ma progression** → **Exporter** → le menu Partager s'ouvre → **Enregistrer dans Fichiers**.
- [ ] Le fichier `fluxe-progression-AAAA-MM-JJ.json` est bien dans l'app Fichiers.
- [ ] **Importer** → choisir ce fichier → le message de confirmation indique le niveau, l'XP et le nombre de séances → **OK**.
- [ ] Message « Progression importée. » ; niveau, sessions et journal sont identiques à avant.
- [ ] Importer un autre fichier (par exemple une sauvegarde de Fluxe Suivi) : message clair « … Rien n'a été modifié. », et rien n'a changé.

## 4. Détails visuels (à vérifier en thème clair **et** en thème sombre)

Changer le thème : Réglages → Luminosité et affichage → Clair / Sombre.

- [ ] Carte **« En cours / Reprendre »** (lancer une séance, fermer l'appli, la rouvrir) : fond vert très pâle (vert foncé transparent en sombre) et **liseré vert à droite**.
- [ ] Journal, carte **Activité (7 derniers jours)** : **liseré vert pâle à gauche**.
- [ ] Titres (FLUXE, JOURNAL, nom de l'exercice, gros chiffre) en police étroite, grasse et penchée.
- [ ] Encadré **Ma progression** lisible, boutons Exporter / Importer bien alignés.
- [ ] La barre du bas (⚡ Fluxe / 📊 Journal) ne cache rien d'important.

Si un point ne va pas : noter l'écran, le thème (clair/sombre) et faire une capture d'écran.
